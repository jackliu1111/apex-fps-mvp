Apex Highlight — 单程序版

macOS：在终端进入本目录，运行 ./apex-highlight tui
Windows：运行 apex-highlight.exe，或在终端运行 .\apex-highlight.exe tui

FFmpeg 和预览播放器已经包含在主程序内。可只复制主程序运行，不需要安装 FFmpeg、Python 或 Go。
选择录像并分析，在候选列表按 P 预览，关闭播放窗口返回，勾选后导出。
运行主程序 doctor 可检查内置媒体工具。

首次运行可能需要按操作系统提示批准主程序。此版本未进行正式开发者签名、公证。
licenses/ 为许可证与可重新构建的源码材料；build-info.json 记录本次构建和自动验证范围。
自动验证不等于所有 Windows/macOS 版本或首次运行系统提示均已验收。
