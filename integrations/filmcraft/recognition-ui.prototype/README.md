# FilmCraft AI 选片 · 可丢弃交互原型

2026-10-13。本轮原型回答：**把枪声／人声识别子行放进原片音频轨下，共用主时间线操作，再拖拽复制到新的编辑轨道，是否更顺手？** 用户已选 A 双行方向，并修订其承载位置和拖拽目标；本轮已完成有界浏览器检查，具体证据见 [CAPTURE.md](CAPTURE.md)，体验结论仍待用户试用。

这是浏览器交互演示，不是 FilmCraft 原生实现。声音事件、分数、波形和分析进度均为演示数据；画面来自本机录像的 0–120 秒静音低清代理。无模型调用、上传、真实导出、磁盘工程写入或浏览器持久化。刷新页面会清空状态，“保存快照／模拟重开”只使用本页内存。

## 启动

在仓库根目录执行：

```sh
python3 integrations/filmcraft/recognition-ui.prototype/serve.py
```

打开 [本地原型](http://127.0.0.1:8791/?variant=A)。也可直接打开本目录 `index.html`；视频预览推荐用上述本地服务，并使用完整桌面浏览器窗口。

服务仅绑定本机，根目录固定在此原型目录；没有接口读取任意本地路径。

保留源预览、节目预览、属性、素材区和时间线的面板位置；把识别操作移入下方主时间线：

- V1/A1 保留原片参照，枪声、人声是 A1 下可展开、折叠的分类子行，与原片共用时间尺、缩放和播放头。

## 本轮操作路径与未覆盖边界

以下列出操作路径，不表示每项均已在本轮复测。已检查轨道对创建、目标轨道内插入与撤销、共尺缩放与折叠、范围调整及预览同步；取消、重复使用提示、组稿和内存恢复等本轮未覆盖的行为见捕获记录。

1. 展开 A1 下的枪声、人声子行，点击高亮定位预览；缩放和移动播放头时，原片 V1/A1 与分类高亮一起对齐。拖左右手柄或输入起止秒数，只改变待剪范围。
2. 拖高亮主体到新的编辑轨道落区，预览落点并创建 V2/A2 的关联声画；后续新增轨道对为 V3/A3。拖入已有编辑轨道时只顺延目标轨道对内容，不改变原片参照、分类行或其他编辑轨道。Esc／无效落点取消。
3. 调整已复制片段的原片起止，删除或撤销其关联声画；确认原片待剪范围与时间线片段双向独立，一次撤销包含本次插入位移。
4. 空白识别区可划选手动补片。重复使用只提示未使用、部分重叠或已使用，不自动删减；提示随当前时间线更新。
5. “按当前范围生成草稿”使用已调整范围；未调整项用默认范围。可包含人声，合并重叠；产生只读原稿与独立副本，原手动序列保留。
6. 用序列下拉框切换手动选片、组稿原稿、编辑副本；节目预览按当前序列播放，时间线空白显示黑场。
7. 演示导入可体验单音轨自动分析、多音轨选择、排队及取消。本地视频选取只替换预览并重新按长度映射演示标记，不代表识别了该视频；静音代理不提供真实音轨试听。
8. 保存快照、修改、模拟重开，检查状态恢复。刷新页面丢失所有快照；这不是持久化验收。

保留键盘替代操作。`Ctrl/Cmd+Z` 撤销时间线操作，`Delete/Backspace` 删除选中编辑片段；边界手柄用左右方向键调整 0.1 秒，按住 Shift 为 1 秒。本轮已观察到范围键盘调整与已创建片段独立，以及插入撤销恢复；其余按键路径未逐项复测。

旧版“操作导览”的范围独立、手动重叠与组稿合并、内存快照恢复场景仍可作为回归依据；本轮以共用时间尺、复制到新轨道对和目标轨道内插入为新增验证重点。

## 边界与结论

- 已确定的产品决策来自 `docs/design/ai-recognition-workspace.md`；原型只用于体验它们，不反向宣称模型效果、原生性能或正式迁移已通过。
- 两分钟代理为 640×360、12 fps、静音；时间标签是交互状态，不代表逐帧剪辑或声画同步验收。
- 项目分栏、音轨混音、特效、任意原生工程载入和实际导出没有在此演示中实现。
- 无生产构建入口；所有文件明确位于 `.prototype` 目录，本轮不会接入正式应用。
- **用户已选择 A 的双行呈现并给出本轮修订。** 当前轨道内整合已完成限定范围的实际浏览器检查，用户体验结论仍待试用；旧版 A/B/C 检查不能替代本轮未覆盖行为。

本轮没有新增测试套件；实际拖拽、点击、键盘及布局检查的有界证据已单独记录于 [CAPTURE.md](CAPTURE.md)，并保留[当前时间线截图](evidence/prototype-timeline.jpg)。整理后的源码提交到 `feature/prototype`；本地临时分支不作为 GitHub 使用前提。产品约定统一维护在[AI 识别与选片方案](../../../docs/design/ai-recognition-workspace.md)，不再在原型目录重复保存设计正文。
