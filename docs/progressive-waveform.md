# 随分析生成的音频波形

2026-10-29：旧版在原片视野超过 60 秒时直接跳过波形解码，截图中的 135 秒视野因此显示空白。短视野还会单独读取和解码音频。

现在在 sequentialAudio 的单次顺序解码中，从原生多声道 AudioBuffer 提取绝对峰值；不保存 PCM、不为波形创建媒体输入或解码器。每个分析预读窗口完成后发布峰值，按视频起点映射到原片时间。波形对应实际用于分析的音轨，界面显示音轨编号；默认轨不可解码而使用备用轨时，它可能与预览声音不同。

波形位于预测区间上方，共用预测视野和时间刻度，裁剪、排除、恢复不会改写它。显示采用平方根幅度映射以呈现低幅度细节，不是响度测量。已解码静音显示中线，未解码或时间戳缺口留空。通常每 50 ms 一个峰值，长录像最多 72,000 个桶。它随复核元数据保存，刷新不需要读回原片；旧版记录无峰值，需要重新分析。重试会重新积累波形，人工决定保留。

验证：
- 65 项 Node 测试通过，覆盖偏移、多声道、静音、缺口、长录像内存上限和持久化。
- verify-analysis-browser.cjs：真实 Chrome/WebCodecs/ONNX，12 秒双音轨，波形从 0 到 10.0535 再到 11.9935 秒；默认静音轨未被第二音轨替代；decoderPasses=1。
- verify-progressive-waveform.cjs：135 秒合成媒体，分析中仍有未解码桶；完成覆盖 134.9935 秒，decoderPasses=1；全片/缩放、刷新恢复、无页面异常通过。
- verify-selection-timeline.cjs：拖动/键盘定位、裁剪、撤销重做、恢复、真实导出、刷新、1440/768/390 三个宽度通过。
- 复核页面截图人工检查：波形和候选同宽、共用刻度；原片参考画面仍独立。局部修复沿用现有视觉设计，没有重新抽取设计方向。
- 设计检查器入口页 0 FAIL / 1 WARN（既有暖灰色调）；空入口检查不替代上述有录像状态的浏览器验证。
