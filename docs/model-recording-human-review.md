## 每个文件的复核方式

1. 从清单打开原录像及对应文件，核对 `artifact_id`、候选版本和文件路径。分别在 Python Web 与 Electron 中实际打开已生成的预览／成片；某入口未操作时保持待审核，不能用 API 或文件播放器替代。
2. 对照首段可辨认画面、片段中间和末段可辨认画面，记录它们在原录像与文件中的时刻。确认内容来自所列源录像、游戏音轨正确、画面／声音没有异常缺失；枪声候选本身不证明本人开枪、命中或击杀。
3. 将可辨认的首尾内容与请求范围及实测视频包范围对照。记录多出的开头／尾部是否符合已展示的快速复制偏移、是否影响本次选片用途。发现不能解释的内容差异或时间偏移时，填写异常位置。
4. 在开头、中段、末尾选择能辨认的音画线索，例如同一原录像中的开枪画面与声音。记录是否发生持续偏移、逐渐漂移、跳音或异常静音。原录像也要对照；若原录像本身有偏移，分别记录，不把来源问题与导出问题混为一个结论。没有可辨认线索时填写 `无法判断`。
5. 为内容、边界／映射、同步、入口播放分别填写结论、审核人和时间，附原录像／成片时刻及证据路径。仅在所有实际要求均已审核且通过后，才能填写该文件整体通过。

## 长录像的页面技术记录

[Python HTTP 页面验收脚本](../scripts/verify_model_web_ui.cjs) 提供两个可选环境配置，供真实长录像执行最小页面闭环。`APEX_UI_STAGE_TIMEOUT_MS` 是每次等待页面状态的毫秒上限，必须为有限正数，默认 45000。`APEX_UI_FIRST_CANDIDATE_ONLY=1` 将当前第一候选真实范围首尾各缩进 0.04 秒，通过公开 DOM 编辑并只勾选这一段；默认仍编辑固定 1.3–7.7 秒并导出全部候选。该配置只影响验收脚本，不改产品规则。

在已经明确设置 `APEX_SAMPLE`、`APEX_SAMPLE_AUDIO_STREAM`、`APEX_MODEL_WORKSPACE`、Python／模型及媒体工具环境后，可按需添加：

```sh
APEX_UI_STAGE_TIMEOUT_MS=180000 APEX_UI_FIRST_CANDIDATE_ONLY=1 \
  desktop/node_modules/.bin/electron scripts/verify_model_web_ui.cjs
```

报告保存模型分析前的页面参数与核心原始参数（阈值 0.2、间隔／前后留白 5／5／5）、真实尺寸／时长／选轨映射、阶段时间与服务配置，再记录脚本将后留白改为 2 秒后的候选、DOM 请求范围、单段导出与实际播放／完整解码。单段模式的 `scope` 明确限制为一份预览和一个独立成片；全部候选导出须引用另一份真实录像技术报告。窗口静音、自动播放／解码与截图均不表示人工感知音画同步通过。
