# Apex Local Cut 产品操作演示视频脚本与录制指引

本文档为 **Apex Local Cut** 官方操作演示视频（建议时长：45～55 秒）的分镜脚本、视觉设计、字幕台词与录制规范，用于录制并制作放在 README 首页和社交平台分享的演示短视频/动图。

---

## 🎯 视频目标与核心信息

1. **核心痛点**：Apex 长时间对局录像动辄几十分钟甚至数小时，手动拉进度条翻找交火既枯燥又耗时。
2. **核心解法**：基于声音模型自动标出枪声候选，**边分析边在原片上调切点**，确认满意后批量导出成片。
3. **核心信任感**：**纯浏览器本地处理**，不需要上传几十 GB 录像，保护隐私。

## 🛠️ 录制技术规范与环境准备

### 1. 录屏环境
- **分辨率**：推荐 `1920 × 1080` (16:9) 或 `2560 × 1440`，保证文字清晰可读。
- **帧率**：`60 fps`（Apex 游戏画面与时间轴拖动必须保证 60 帧流畅度）。
- **浏览器设置**：
  - 桌面 Google Chrome 最新稳定版。
  - 隐藏书签栏（`Cmd/Ctrl + Shift + B`），隐藏浏览器插件图标，进入纯净窗口模式。
  - 页面缩放比例保持 `100%`。
- **录像素材**：
  - 准备一份 5～15 分钟的真实 Apex 录像（含 2～4 处明显交火）。
  - 或者直接使用本地部署的 `--sample` 1 分钟真实交战样本，流程紧凑。

### 2. 光标与后期建议
- **鼠标指针**：启用操作系统或剪辑软件中的“高亮光标”或平滑移动，点击时显示水波纹微动效。
- **加速处理**：对于分析进度条或导出编码较慢的片段，在剪辑时以 `3x ~ 5x` 倍速快进，并在画面角落标注小字：“⏳ 分析过程已加速展示”，避免误导用户。
- **音效设计**：
  - 背景音乐（BGM）：低调轻快的电子/科技感节奏（音量控制在 15%~20%）。
  - 关键操作音效：拖入文件、手柄吸附、按键敲击、导出成功的提示音（轻微清脆）。
