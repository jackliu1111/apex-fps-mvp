# Mac arm64 移交验收

此清单用于另一台无项目开发环境的 Mac，完成 issue #17 剩余验收。目标用户不需要安装 Node、Bun、Python、PyTorch 或 FFmpeg。自动界面控制脚本仅在开发主机使用；目标机以实际桌面界面操作，用 macOS 自带命令和包内媒体工具留档。

- 包采用本地ad-hoc签名，严格资源seal已通过；没有Developer ID或公证，当前 `spctl` 评估仍拒绝。不能称为已通过下载/安装信任的正式发行包。

对外分发仍需确认媒体工具许可/源码交付材料以及签名/公证策略。本包用于经确认的本地验收，不发布。

## 实际桌面闭环

在Finder打开完整 `.app`，不调用源码、Web入口或独立Python CLI来代替。保存界面截图/录像，按真实路径和音轨记录：

| 复核 | 预览实际播放；勾选/取消与范围修改保留完整预测；保存候选和请求范围，必要时重算确认旧预览不会复用 |

## 正常退出与结果留存

所有任务已结束后，先保留真实运行PID再退出：

```sh
/bin/sh verify_model_desktop_mac_handoff.sh \
  "$HOME/验收资料/中文 移动安装目录/Apex Model Review.app" \
  "$HOME/验收证据/Mac arm64" before-quit
```

在应用菜单正常退出或关闭窗口，再运行 `after-quit`。脚本有限等待5秒，检查先前实际捕获的app/core/guardian/model/media/renderer PID是否仍在，以及该安装路径是否仍有匹配；它不终止任何进程。没有非空的退出前记录时会拒绝声明通过。保存原记录及检查结果；单凭窗口消失或事后空列表不算完整退出证据。若尚有进程，记录失败，不按名字批量杀其他用户应用。

进程根仅按实际命令的安装路径前缀匹配，再展开后代，不把collector自身参数中出现 `.app` 路径当作应用。必须在本次运行中采样，不能复制历史报告的PID充作新的退出前记录。无应用时拒绝采样与历史已退出PID检查的真实CLI回归，见 [验证记录](desktop-validation.md)。

```sh
/bin/sh verify_model_desktop_mac_handoff.sh \
  "$HOME/验收资料/中文 移动安装目录/Apex Model Review.app" \
  "$HOME/验收证据/Mac arm64" after-quit
```

该阶段也重新检查完整资源seal，确认模型缓存/`__pycache__`等没有破坏安装内容。另记录已完成结果/文件可恢复和未完成文件清理（如测试中确实发生取消/故障）；不能根据未运行的故障场景填pass。
