# 导出工作区设计

2026-10-28。依据交接文档与 `.taste-skill/export-review/critique.md`，交付独立 HTML/CSS/JS 交互设计稿，未接入正式编码器、文件系统或复核存储。

打开 `index.html` 即可体验，或在此目录运行静态服务。`?view=tasks` 直接进入任务状态示例。

## 窗口与信息层级

沿用 Apex Local Cut 顶部三入口：分析队列 / 片段复核 / 导出工作区。导出是可停留、可离开的完整工作区，不是阻塞复核的大弹窗。设计稿中的其他导航仅示意位置。

- 待导出回答：哪些录像中的哪些片段将以什么规格输出？主区域按来源分组，跨组勾选。每条包含片段名称、原片位置条、起止时间、时长、最终尺寸、格式和帧率。主操作为提交所选片段。
- 任务记录回答：每一条到了哪一步、哪一条需要处理？列表逐条显示进度与操作。默认设置旁明确标明只影响下一次提交；已提交规格固定。
- 右侧 320px 设置区：格式、分辨率、帧率、保存位置、选中总时长、提交。1440px 下画布 1216px = 列表 872px + 间距 24px + 设置 320px。
- 768px 将规格移至片段次行，保留设置栏。390px 设置区置于列表后，列表前提供设置跳转及提交入口。

## 交互决策

1. 加入待导出时保存范围快照；复核修改不静默改写草稿。需要改变范围时显式重新加入。正式接入需要按来源与范围识别重复，提示替换或保留，避免误提交。
2. 提交时冻结来源、范围、规格及保存目的地。默认值调整仅更新待导出的有效规格。
3. 初始 MP4 / 跟随原片尺寸 / 跟随原片帧率。设计候选为最高 1080p、720p 与最高 60、30 fps，保持比例且不升采样。原型以短边限制尺寸、编码尺寸取偶数；正式接入需验证横竖屏、旋转和 VFR，帧率未知时不得伪造精确值。
4. 单条串行执行即可实现后台工作区；不以分析队列清空为启动条件。资源争用与调度属于正式实现验证范围。
5. 移除草稿不删除原录像与复核选片。取消仅影响该任务；失败保留范围与规格，重试重新排队，不改写其他片段。
6. 网页关闭/刷新会中断执行。刷新恢复的历史任务应显示“已中断”，提供重新关联录像/重新授权目录后重试，不显示仍在导出。

| 状态 | 行内反馈 | 操作 |
| --- | --- | --- |
| 排队 | 空进度轨道、排队中 | 取消 |
| 编码 | 实际编码百分比 | 取消 |
| 保存 | 编码 100%，正在保存 / 写入收尾 | 按后端能力取消 |
| 下载就绪 | 编码 100%，尚未保存 | 下载 |
| 已保存 | 目录文件关闭成功后显示 | 详情 / 可用时打开位置 |
| 失败 | 行内原因，保留已提交规格 | 重试 / 重新授权 |
| 已取消 | 明确状态 | 重试 |
| 已中断 | 刷新后恢复的非终态任务 | 关联资源后重试 |

浏览器下载无法确认用户是否最终保留文件，不能点击下载即标为“已保存”。大文件需要可用输出目录时，应在提交前就地阻断并给出选择目录入口，不等编码结束才提示。目录权限和缺少来源属于预检；剩余时间无可靠估算时不显示。

## 原型范围与数据

可以操作：全选/单选、移除、空状态、规格联动、本地记住默认值、模拟提交、单条取消/重试、片段详情、任务状态示例。顶部“演示逐条进度”装入静态状态集合；实际点击提交会产生模拟进度。没有真实导出、目录选择、下载、跨页面后台运行或任务持久化。重新载入会重置示例任务，只保存设计稿专用的设置键。

示例：Apex 周末排位.mp4（1440p/60）、Apex 晚间对局.mp4（1080p/30）；山脊交战、房区反打、决赛圈收尾、落点遭遇、高台压制、撤离掩护共六条，26+35+42+19+31+24 = 177 秒（02:57）。任务记录中的百分比、完成、失败及错误原因都是示意。正式实现替换为媒体元数据和队列事件。

无外部照片、字体下载或素材依赖。原片位置条由真实比例计算的示例时间范围绘制；不以虚构游戏缩略图冒充原录像。
