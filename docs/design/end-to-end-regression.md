# Apex Local Cut 端到端回归测试设计

覆盖用户从导入录像、分析与复核到保存成片的流程，以及监听目录自动接入和刷新后的会话边界。共 8 个场景、28 个验收分支。前 5 个场景的 17 个分支直接覆盖批量导入、播放轴和按钮归属问题。

## 1. 怎样判定一个分支通过

每个分支包含一个可观察的前置状态、一次用户操作或后台事件，以及预期结果。同步等待具体事件，例如 A 行变为就绪、B 的首帧解码完成、文件写入流关闭。固定等待几秒不能证明目标事件发生。前置状态没有到达时，用例应失败并标出失败步骤。

- **操作归属**：在有 A、B 两份录像的场景，同时核对列表选中项、播放器实际画面、一次后续操作的结果。三者都指向用户最后打开的录像。
- **时间位置**：暂停或跳转后，画面内的时间码与目标相差最多一个素材帧周期。播放中检查连续帧向前推进，测试区间避开自然结束。播放器命令接受了目标时间，只是中间证据。
- **瞬时错误**：在受控异步事件放行前开始记录加载请求、媒体切换和显示帧。断言约束区间内错误录像出现次数、意外重载次数均为 0。最终截图用于辅助定位。
- **保存结果**：用户界面的已保存数量、成功关闭的文件数、目录中可重新打开的输出一致。部分失败按文件核对。

### 素材与时序

批量导入使用三份小型可解码视频、其中一份的重复文件和一个损坏文件。跨录像用例另准备两份 12 秒、固定帧率的视频，在每帧烧录 A/B 标识和帧号。给 A 设置三段稳定候选，第一段从 1 秒开始；给 B 设置两段，范围分别为 4–6 秒和 8–10 秒。固定候选允许导航断言精确到片段和帧。另保留一条从文件输入框导入、运行真实模型直至就绪的流程。

并发用例在分析结果交付或媒体加载完成边界设置测试用的可释放等待点。先观察任务确已到达等待点，再通过页面操作建立前置状态，最后放行真实的完成处理。控时工具只决定交付顺序；选中项、播放状态和按钮效果由产品代码产生。每条用例使用独立页面、临时输出目录，并清理所设置的等待点。真实长录像和 Windows 文件系统的耗时由单独的实机验收记录。

末列描述当前工作区中可复用的断言或待补的部分。“标准”指 npm 的 E2E 入口，“专项”指独立运行的浏览器脚本，“逻辑”指 Node 测试。以下是用例设计与源码盘点，运行结果需另行登记。

### 场景四　视频全片播放轴（3）

| 编号 | 前置状态与触发 | 通过条件 | 当前依据与缺口 |
|---|---|---|---|
| T1 | 已知 8.04 秒有枪声，对应临时候选为 8.00–8.06 秒 | 视频播放轴有临时区间；红色位于该区间内；短区间左右边界相对轨道的位置误差各小于 1 CSS 像素 | 专项已有分布画布和区间几何断言；补合成画面检查以发现上层完全遮挡 |
| T2 | 暂停在固定帧，将同一候选从临时更新为稳定 | 同位置只有一个标记，虚线转稳定样式；暂停帧和人工决定保留 | 补同一区间状态切换 |
| T3 | 进入全屏，在全片轴拖动后退出全屏 | 两种尺寸下用各自轨道宽度计算边界；枪声可见；拖动终点、读数和解码帧一致 | 已有普通及全屏区间专项、拖动专项；复用同一素材比对 |

期望横坐标为轨道内容区左边界加上“视频时间 ÷ 视频总时长 × 内容区宽度”。单独一处红色分数峰可能被候选平滑规则过滤；测试几何关系时应使用已知存在的候选。

## 3. 如何分批落地与复验

1. **先补 B1、B2、B3。** 每个事件顺序单独命名、独立运行。B1 和 B2 复用 A 完成事件，分别证明暂停帧保留和播放帧推进；B3 单独控制的是旧媒体加载。三者失败时必须能看到放行顺序、选中录像、画面标识和最后一次按钮操作。
2. **再补 N2、N3、T2、R2、R3。** 已有批量导入用例继续覆盖正常入口。间隙左右查找、所有按钮禁用组合、候选合并和裁边数值用表驱动逻辑测试展开。浏览器层每类保留能发现事件绑定、画面或保存结果错误的代表路径。
3. **目录、权限、会话与全屏按改动触发专项。** 浏览器内的私有文件系统（OPFS）适合稳定模拟目录写入与撤权。Windows 报告的加载慢另用 Edge、实际存储位置、同一组录像采证，记录选入至出现行、读取轨道、等待队列、首个可复核片段的分段时间。建立同机同素材基线后再定性能阈值。未完成录制到停录接入的验收使用真实 OBS 文件。
4. **执行与证据。** 当前标准入口为 `npm run test:e2e`；聚焦批量导入使用 `npx e2e run tests/batch-import.e2e.ts`。核对测试服务加载的是待验收工作区。每次执行记录分支编号、提交或工作区版本、浏览器、素材、是否控制异步顺序、结果及失败 trace。平台或权限未验证时单列。上列“待补”项实现并运行通过后再更新覆盖记录。
