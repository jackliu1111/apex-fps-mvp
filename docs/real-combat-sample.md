## 使用

从仓库根目录启动静态页面，并显式传入样本：

```sh
python3 model_web_ui/browser.prototype/serve.py \
  --sample '/Users/jackliu/.codex/artifacts/apex-fps-mvp/real-combat-sample-20261028/apex-combat-60s.mp4'
```

打开服务地址，使用真实样本按钮；也可将该 MP4 当作普通本地录像导入。服务仅提供已有媒体文件，运行时不调用 FFmpeg。未配置样本时应提示导入或配置已有文件，不回退为合成画面。

合成素材保留在测试夹具中，用于音轨回退、确定性边界与错误恢复等自动化检查；不再作为面向用户的示例素材。

## 重新制作与验证

生成脚本要求系统已有 FFmpeg / ffprobe，拒绝覆盖已有 MP4 或清单。传入新的输出路径后执行：

```sh
python3 scripts/create_browser_combat_sample.py \
  '/Users/jackliu/Downloads/2026-09-11 20-32-49.mkv' \
  '/Users/jackliu/.codex/artifacts/apex-fps-mvp/real-combat-sample-NEW/apex-combat-60s.mp4' \
  --start 630
```

脚本固定截取 60 秒，限制视频码率并设置 90 MiB 文件保护上限；输出读回必须接近 60 秒且低于该上限才接受。生成后运行 FFmpeg `-xerror` 全量音视频解码，并保存来源元数据、截取区间、完整编码命令、产物 SHA-256 和解码结果。当前实物的 ffprobe 时长为 60.000 秒，全量解码退出码为 0。小型生成清单保存在 [样本证据](../model_web_ui/browser.prototype/evidence/real-combat-sample-20261028.json)。

本次检查发现 `/Volumes/EXTERNALUSB` 没有挂载，因此没有创建同名本机目录、下载或复制任何大文件。已有本机原录像仅被只读访问；新增 MP4、清单与检查截图合计不足 40 MiB，低于单文件 100 MiB 和任务累计 1 GiB 的外接盘阈值，故存放于本机独立产物目录。当前样本使用不依赖外接盘；原片只在重新制作时需要。视频和截图不提交到 Git，仓库只保留脚本、文档和小型 JSON 清单。
