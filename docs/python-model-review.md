# 模型候选复核、按需预览与独立导出

对应 [#8](https://github.com/jackliu1111/apex-fps-mvp/issues/8)、[#9](https://github.com/jackliu1111/apex-fps-mvp/issues/9)，并与 #7 的候选版本、#10 的素材身份、#11 的取消恢复共用核心。公开测试边界沿用 PRD #3 已确认的逻辑服务操作，不对内部模块或私有方法建立测试。

`update_selection` 保存候选版本关联的勾选状态和请求范围。自动候选与原始预测保持独立；部分更新不改其他候选。起止必须是有限数值，满足 `0 ≤ start_s < end_s ≤ video_duration_s`。畸形选择、未知候选、过期版本、源文件或分析配置变化均返回明确错误。

`request_preview` 返回后台任务引用，仅生成请求的候选。预览按已确认的录像视频原点和音轨索引裁剪，以 H.264/AAC MP4 输出，最大宽度 1280。预览缓存通过结果、候选版本、候选标识和请求范围关联到独立预测及其源身份／音轨／模型／前处理配置。同一范围复用缓存；修改一段范围只使该段旧缓存不可读取；重算候选拒绝整个旧版本。每次读取已注册预览也会核对源身份和配置。HTTP 和 Electron 资源适配支持 byte ranges，播放定位无需读完整文件。

`export` 默认 `mode: "copy"`。每个所选候选输出一个文件，按请求范围起点排序，使用 `{output_dir}/{media_id}/{task_id}/001.mp4` 等路径；重复导出使用新任务目录。空选择不生成目录或输出。不能将源文件或媒体／任务／预测／资源记录目录作为输出目标。FFmpeg 使用禁止覆盖参数，失败或取消删除当前半成品，保留已完成文件及注册记录。

快速复制先选请求起点之前最近的视频关键帧，再复制至请求终点。实际范围采用**源录像视频包的呈现时间范围**：读取输出视频包 SHA-256 序列，从已选择的源关键帧逐包核对完整序列，再使用匹配源包的最早 PTS 和最大 PTS + duration 计算覆盖范围。无法对应的输出明确失败并清理；不会将请求范围当作实测范围。`measurement` 字段记录该方法。B 帧、包边界和音频编码块可能使终点也偏移；该测量不表示人工感知同步已验收，也不表示音频包覆盖范围与视频完全相同。

审查阶段将源视频包哈希改为每个导出任务只扫描一次，使用磁盘临时索引供各片段核对，现有行为场景继续通过。每段前后仍进行完整源身份核对，有额外全文件 I/O；长 4K、多候选任务的总导出性能仍需代表性素材测量，不能由“复制不重编码”推定总耗时。

目前 MP4 复制接受 H.264、HEVC、AV1、MPEG-4 视频及 AAC、MP3、ALAC 音频，由实际媒体工具决定是否执行成功；其他流组合返回 `copy_incompatible`，执行失败不会改为重编码。契约保留 `mode`，精确重编码目前返回 `export_mode_unavailable`，配置与页面只提供快速复制。按需预览的重编码不能计为精确成片导出能力已验收。

每个完成文件保存源身份、音轨、预测 ID、候选版本、候选标识、最终选择、请求／实测范围、模式及路径。`get_task` 返回逐文件 `completed`、`failed` 或 `cancelled` 状态，失败项没有成功路径或实测范围。`get_artifact` 只接受注册 ID；导出文件可在重启后继续读取。预览与导出任务记录阶段耗时、媒体日志路径和当前待清理路径；取消先返回 `cancelling`，结束进程及清理后才返回 `cancelled`。
