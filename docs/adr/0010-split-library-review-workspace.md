# 录像库与片段复核合并为左右分栏的本地选片工作区

[ADR 0009](0009-recording-library-auto-intake.md) 把录像库定为唯一主入口，但保留了独立的复核页面。玩家的实际循环是「打完一局切回浏览器 → 看最新录像 → 复核 → 导出 → 下一局」，录像库在这个循环里只是复核的入口与切换器：一个会话通常不超过 10 条录像，占满整页浪费空间，录像库与复核页之间来回跳转，复核页里的录像下拉框又与录像库重复承担切换职责。

因此决定：**录像库与片段复核合并为同一个左右分栏的本地选片工作区，左侧是录像库栏，右侧是当前选中原录像的片段复核；整页式录像库只在录像库为空时作为首次引导出现。** 本决定部分取代 ADR 0009 第 1 条中「复核工作台保持不变」的部分；导出任务页面保持不变。

## 决策

1. **工作区形态**
   - 顶部导航只保留「选片」与「导出任务」。
   - 录像库为空时显示整页两步引导：选择录像监听目录 → 开启对局监听；手动导入作为次要入口。只要有一条录像即进入分栏。
   - 片段复核不要求录像已就绪，右侧可以打开任意状态的原录像。
   - > 已被 [ADR 0011](0011-always-split-sidebar-intake.md) 部分取代：取消空库时的整页两步引导，选片视图在 0 条录像时也始终保持左右分栏布局。

2. **录像库栏**
   - 扁平列表，最新的在最上面，不按状态分组。
   - 每行：录制时间与时长、截断的文件名（悬停显示全名）、状态点、`候选数 · 已导出数`；不显示文件大小。
   - 状态只有四种：未分析、分析中 %、已就绪、已就绪 ⚠ 粗略。对齐可信度仍然保留，界面只在粗略对齐时提示。
   - 行只负责选中，不放操作按钮；新出现的录像标「新」，打开后消失。
   - 桌面端默认展开，可折叠为只显示时间与状态点的竖条并记住选择；窄视口改为从左侧滑出的抽屉。
   - 「导入视频」位于录像库栏顶部；整个工作区都能接收拖入。

3. **右侧复核区**
   - 顶部承载当前录像唯一的主操作：未分析 →「开始分析」，分析中 →「停止」，粗略对齐 →「重新离线分析」。
   - 移除复核页的录像下拉框与返回录像库按钮；提供在录像之间上下切换的快捷键。

4. **全局状态**
   - 对局监听与录像监听目录是会话级状态，移入全局顶栏，在所有页面都可见与操作，不放在录像库栏内。
   - > 已被 [ADR 0011](0011-always-split-sidebar-intake.md) 取代：对局监听与录像监听目录统一迁入左侧录像库栏顶部，移除全局顶栏胶囊；折叠竖条保留紧凑状态圆点。

5. **新录像不打断复核**
   - 页面在后台期间有新录像就绪时，玩家切回页面，右侧切到最新就绪的录像。人工复核决定已自动保存（[ADR 0004](0004-preserve-review-decisions.md)），切换不会丢失工作。
   - 玩家一直停留在页面上时不自动切换，只在录像库栏标「新」并给出轻提示；手动导入同样不切换，录像库原本为空时除外。

## 被拒绝的替代方案

- **整页录像库，原地替换分析队列（ADR 0009 原方案）**：改动最小，但需要在录像库与复核页之间来回跳转，录像切换职责重复，几行内容占满整页。
- **浮窗或弹出面板承载录像库**：会把主入口和会话级状态藏起来，与复核时间轴的焦点和快捷键冲突；Apex 独占全屏时浏览器浮窗也无法盖在游戏之上，画中画小窗已在 ADR 0009 中暂不纳入。
- **横向录像条放在播放器上方**：节省宽度，但放不下状态与候选计数，录像多时需要横向滚动。

## 影响

- 录像库纯视图层只依赖状态快照与回调，可直接复用为录像库栏；行内操作回调改由右侧复核区顶部触发。
- 后续接入后台引擎与就绪提示的工作，以本决定的控件位置与切换规则为准。
