# 人工复核决定独立于自动候选保留

调整筛选参数会使自动候选的边界、数量和分组发生变化，但用户已经修改的范围、明确保留和明确排除的决定必须继续有效。自动候选与人工复核决定分别保存，调参只更新自动建议，不覆盖或清空人工操作；只有用户主动重置时才清除对应决定。自动默认勾选不视作人工保留。

这一决定替代旧方案中“重算创建新候选版本并清除旧选择与范围”的行为。代价是需要处理新候选与已有决定之间的关系，不能继续仅凭候选列表位置、起点或当前版本识别用户意图。人工裁好的片段即使不再被新参数检出，也仍保留；候选变化不能使已排除内容自动重新进入导出选择。

新候选与原排除范围重叠时，原排除决定保持有效，新候选默认不勾选，作为补充建议供用户主动处理；完全重复的已排除候选不再出现。不因新候选扩大而自动扩大原排除范围。具体交互见[并行交互方案](../design/parallel-analysis-review.md#调参与人工复核决定)。
