# 分析与复核独立推进

分析和复核作为两个可以并行推进的任务：分析持续产生后续时间线的枪声候选，用户在完整原录像的时间线上观看和调整选片，以已产生的稳定候选作为定位线索。分析页和复核页分别组织对应操作，进入复核页本身不暂停分析；页面导航不决定任务是否运行。这个选择让用户能够在整片处理完成前开始选片，同时要求任务进度、用户当前查看位置与人工修改分别维护，不能继续依赖一个全局活动状态控制所有操作。

单次读取约束只作用于分析链路：连续取得的音频应共享给推理及可选缓存，避免为不同分析产物重复扫描原录像。复核和导出允许按需读取原片，并允许利用附近关键帧简化媒体处理；不要求首次扫描时预先生成全部视频预览。具体页面与交互见[并行交互方案](../design/parallel-analysis-review.md)。本决策不选择新的产品宿主，也不替代共享 Python 双入口的 ADR 0002。
