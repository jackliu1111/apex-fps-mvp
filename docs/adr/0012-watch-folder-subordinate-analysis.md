# 实时音频分析与自动离线分析收归录像监听目录，移除虚拟声卡输入

纯网页环境下，[ADR 0009](0009-recording-library-auto-intake.md) 与 [ADR 0011](0011-always-split-sidebar-intake.md) 将「对局监听」与「录像监听目录」作为左侧录像库栏顶部的两个平级控件，并在弹窗中提供「音频设备 / 虚拟声卡（`getUserMedia`）」与独立音轨防回环豁免。实际评审暴露出四处体验与模型摩擦：

1. **平级呈现造成职责混淆与空转**：实时音频分析的唯一消费者是录像监听目录自动接入的新原录像（手动拖入文件不参与升格）；未选目录时允许单独开启实时分析没有任何下游消费，且「对局监听」与「录像监听目录」双重“监听”容易让用户误以为网页在检测游戏状态或录屏。
2. **输入设备列表误导普通玩家**：`getUserMedia` 列出的是本机麦克风等音频输入设备，除非用户额外安装 VB-Cable / VoiceMeeter / BlackHole 等虚拟环回声卡，否则无法用于采集游戏输出声音，反而容易误选麦克风。
3. **未覆盖录像的自动分析策略缺少选择权**：对于 30GB 级 MKV 长录像，后台自动离线解封会完整顺序读取 30GB 文件，在玩家连开下一局时与游戏及录屏软件争抢磁盘 I/O；但对短录像或独立高速盘用户，落盘即自动离线分析又更省心。
4. **纯网页实时音频分析仍具不可替代性**：面对 30GB / 44 分钟 MKV 长录像，实测离线全片分析耗时约 209 秒（其中 196 秒消耗在容器全扫），而实时音频分析仅在停录升格时跳读 15–30 秒音频切片即可全片就绪，是纯网页零安装边界内唯一能避开局后重盘扫描的方案。

因此决定：**继续坚守纯网页零安装边界，将「实时音频分析」（原「对局监听」）与新增的「自动离线分析」统一收归为「录像监听目录」下的独立可选开关（默认均关闭），移除 `getUserMedia` 虚拟声卡/音频设备输入路径及防回环豁免，并将左侧栏接入区收敛为「1 行紧凑监听目录状态条 + 统一自动接入设置浮层」。** 本决定部分取代 ADR 0009 第 2 条与 ADR 0011 第 2 条。

## 决策

1. **领域从属与命名统一**
   - 原「对局监听」更名为**实时音频分析**（`Live Audio Analysis`），明确其“纯音频、实时算枪声、不采集不显示画面”的真实职责；与全站「录像分析 / 未分析 / 开始分析」词汇对齐。
   - **实时音频分析**与**自动离线分析**均隶属于**录像监听目录**。未选择目录或刷新后处于「需恢复权限」状态时，不允许开启实时音频分析。
   - 实时音频分析运行中「切换目录」不中断当前采集与 60 分钟声音历史；点击「停止监听」或目录监听失效时联动停止实时音频分析。

2. **移除虚拟声卡输入，纯网页仅保留系统音频**
   - 移除 `getUserMedia` 音频输入设备枚举、切换界面及「非静音回放时保持监听」防回环豁免开关。
   - 实时音频分析仅保留系统音频（`getDisplayMedia`）单一路径：拿到流后立刻停止并移除视频轨，并在界面显式告知浏览器会弹出共享框但仅采集系统音频、不录制也不显示画面；页面内非静音回放原录像时始终自动暂停防回环。

3. **录像监听目录下提供两个默认关闭的独立开关**
   - **自动离线分析**（持久化偏好，默认关闭）：开启后，未被实时音频分析覆盖的新落盘录像自动入队执行录像分析；关闭时仅接入为「未分析」，由用户按需手动启动，避免 30GB 级大录像在游戏期间后台抢盘。
   - **实时音频分析**（本会话运行态，默认关闭）：开启后实时采集系统音频计算枪声预测，停录后直接原片升格免整片扫描。两项同时开启时，实时覆盖到的录像优先原片升格，漏覆盖或断流后的新录像由自动离线分析兜底。

4. **侧栏 1 行紧凑状态条 + 统一「自动接入设置」浮层**
   - 左侧录像库栏顶部收敛为单行监听目录状态条（未设置 / 需恢复权限一键恢复 / 监听中 + 实时状态徽标或异常告警 + 设置齿轮；桌面端折叠为竖条时收敛为单个状态圆点按钮）。
   - 所有可选项（目录切换、新增的「停止监听」、自动离线分析开关、实时音频分析开关与提示、静默就绪浏览器通知开关）统一归入「自动接入设置」浮层。

## 被拒绝的替代方案

- **引入本机伴随进程（WASAPI Loopback）或打包桌面端（Tauri / Electron）以消除浏览器共享框**：可彻底去掉屏幕共享弹窗，但破坏纯网页零安装分发优势，留待核心留存验证后再评估。
- **在纯网页版彻底移除实时音频分析**：虽可进一步简化代码并消除共享框摩擦，但无法解决 30GB MKV 长录像停录后 ~3.5 分钟全盘扫描与磁盘 I/O 争抢问题；将其降格为默认关闭的目录下可选加速项即可做到对不使用者零打扰。
- **把监听目录及开关全部迁入全局顶栏设置弹窗**：虽能让录像库侧栏更空，但会遮蔽刷新后「恢复监听」与实时分析运行态/断流告警的可见性。
