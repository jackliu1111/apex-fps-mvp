# 固定导出批次并自动保存选片工作

> 2026-10-30 状态补注：本 ADR **部分被取代**。提交即固定导出批次的决定继续有效；跨刷新自动保存选片与恢复记录的部分已在 `938ccda`（keep review workspace scoped to the current session）移除，当前仅保留页面会话状态。以下正文保留为历史决定，不是当前持久化能力说明。成片保存与取消的后续决定见 [ADR 0006](0006-directory-only-export.md)（已接受、尚未实现）。

允许用户在整份录像分析完成前提交范围已经确定的选片。提交时固定该批的来源、片段集合、请求范围及声音和输出设置，包括尚在排队的批次；后续分析、调参或人工修改只影响下一次提交，不改变这一批。这样用户可以继续复核，同时接受已提交输出与当前编辑内容可能不同，界面需提示尚未导出的修改。

选片范围、人工保留与排除决定、补充建议处理状态和复核位置自动保存，优先保证刷新或重新打开后不丢失人工工作。分析断点续算后置；恢复选片和批次记录不代表后台任务仍在运行，也不代表导出成片已保存到磁盘。保存和恢复的状态需按实际结果表达，完整规则见[并行交互方案](../design/parallel-analysis-review.md#导出与自动保存)。
