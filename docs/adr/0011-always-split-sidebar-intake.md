# 常驻分栏选片工作区与录像库侧栏接入控制

[ADR 0010](0010-split-library-review-workspace.md) 将录像库与片段复核合并为左右分栏的本地选片工作区，但保留了「空库时显示整页录像库两步引导」与「全局顶栏挂载对局监听/录像监听目录胶囊」两项过渡设计。实际使用暴露出两个核心体验断层：

1. **空态整页录像厅导致单向不可逆跳转**：玩家首次进入看到的是大标题「录像库」与两步监听大厅，但顶栏只有「选片」和「导出任务」两个入口；一旦导入或接入任意一条录像，该整页视图即永久消失并切换为左右分栏，后续从选片或导出任务切回都无法再回到最初的引导/监听大厅，破坏空间连续性与返回预期。
2. **接入职责割裂与视觉冗余**：「录像监听目录」「对局监听」与「导入视频」本质上同属录像库的输入源（接入控制），把前两者放到全局顶栏、把手动导入与文件清单留在左侧录像库栏，并在空库时再渲染一套两步大卡片，造成同一组状态多处重复且挤占顶栏空间。

因此决定：**取消空库时的整页录像厅，选片工作区在任何录像数量下始终保持「左侧录像库栏 + 右侧片段复核」的常驻左右分栏结构；同时将「录像监听目录」与「对局监听」控制彻底迁入左侧录像库栏顶部，移除全局顶栏的监听胶囊。** 本决定部分取代 ADR 0010 第 1 条与第 4 条；其余条款（扁平列表、四种状态、右侧主操作、窄视口抽屉、折叠竖条、新录像不打断复核）全部沿用。

## 决策

1. **常驻左右分栏（取消空态整页录像库）**
   - 顶层导航保持「选片」与「导出任务」两个视图。
   - 进入「选片」视图时，无论录像库为 0 条还是多条，始终展示同一套左右分栏布局（桌面端左侧录像库栏 + 右侧片段复核区；窄视口 ≤ 900px 时录像库栏收起为左侧滑出抽屉）。
   - 录像库为空时，左侧录像库栏顶部直接提供接入控制与拖入/导入区，右侧复核区保持就位并展示简洁的空态提示与禁用态工具栏，不再出现独立整页录像库引导。

2. **接入控制归入左侧录像库栏顶部**
   - 移除全局顶栏（`.app-header`）中的对局监听与录像监听目录胶囊，顶栏只保留品牌、导航（官网入口 / 选片 / 导出任务）与全局工具（诊断、语言切换）。
   - 左侧录像库栏顶部依次承载完整的录像接入区：
     - **录像监听目录**：显示当前只读监听目录状态与目录名，支持点击切换目录，并在权限需恢复时提供一键「恢复监听」入口；
     - **对局监听**：一键启停纯音频实时监听，并保留悬浮设置弹窗（系统音频 / 虚拟声卡设备切换、独立音轨防回环豁免、静默就绪系统通知开关）；
     - **导入视频**：手动选择本地录像文件（同时继续支持全工作区拖入）。

3. **折叠竖条与导出页的连续性**
   - 桌面端将左侧录像库栏折叠为窄竖条时，竖条顶部保留紧凑的目录监听与对局监听状态圆点按钮（通过颜色与悬停提示传达当前状态，并可直接操作），不丢失监听状态感知。
   - 切换至「导出任务」页面期间，后台对局监听、目录监听与原片升格持续运行，不中断采集；返回「选片」即可在左侧录像库栏查看状态与新接入录像。

## 被拒绝的替代方案

- **保留独立「录像厅」并在顶栏增加第 3 个导航标签**：虽可解决“跳走回不去”的问题，但会重演 ADR 0010 已经否决的“选片与录像库各自管理录像、来回跳转”的职责重复，增加不必要的信息层级。
- **主控迁入左侧栏但顶栏保留只读状态灯**：仍会在顶栏重复表达同一份会话状态，挤占窄桌面顶栏横向空间；导出页停留时间极短，后台监听与静默提示（标题角标/可选系统通知）已足以覆盖状态提醒。

## 影响

- `site/split-workspace-controller.mjs` 中 `resolveClippingLayout` 在选片视图下恒返回 `'split'`（独立录像库视图仅保留给 `?libraryPreview` 纯视图调试入口）。
- `site/global-topbar-controls.mjs` 演进为 `site/library-intake-controls.mjs`，接入控件挂载至 `#analysis-page .queue-panel` 头部，移除 `#global-session-controls` 与 `#empty-onboarding`。
- 录像库栏 `.queue-panel` 避免对悬浮设置弹窗做 `overflow: hidden` 裁切，确保展开态、折叠竖条态及窄视口抽屉态均无裁切与水平溢出。
