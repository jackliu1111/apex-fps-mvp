# ADR 0007 实现与验收记录

日期：2026-10-30。对应 [ADR 0007](../adr/0007-decouple-clip-selection-from-exclusion.md)。本地实现与 Chrome 验证完成，尚未部署。

## 实现

- `review-workspace.mjs` 为每份录像独立保存导出勾选状态。`choose` / `chooseAll` 只改变勾选，不再写入保留或排除决定；候选的身份、范围和当前编辑位置不因取消勾选而改变。
- 自动候选按原录像中的精确范围关联勾选状态，同范围重新发布或候选键变化时仍保留勾选；人工裁边按决定 ID 保留勾选。新范围继续遵循原有候选与补充建议规则。
- `exclude` 是明确排除的入口。工作区返回带 `excluded` 标记的占位片段；列表与时间轴共用“显示已排除”，并分别提供恢复入口。批量勾选跳过已排除和未稳定片段，不能隐式恢复排除项。
- 取消勾选后列表行和时间轴标记保留并弱化；列表行的焦点和当前编辑状态保留。“全不选”不会清空候选，也不会禁用“全选”。全部排除时有明确恢复提示。
- 勾选、批量勾选、裁边、排除和恢复进入当前录像的撤销/重做历史。批量选择一次撤销，不改变分析、播放视野、其他录像和已提交批次；重复选择同一状态不增加空撤销步骤。
- “退出选片”改为“全片视野”，只恢复原片轴缩放，不清空当前编辑片段或导出勾选。移除试用和提交导出按钮的 `↗`。

本次只落实 ADR 0007；音量、选区试听、全局快捷键、滚轮手势与调度生命周期重构不在本次实现范围内。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 全部 Node 测试 | 83 / 83 通过 |
| `verify-clip-selection.cjs` | 取消勾选保留 DOM 与焦点、全不选/全选、未勾选裁边、两个视图同步排除/恢复、Delete 防连删、撤销/重做、全片视野不改选择均通过 |
| 固定批次真实导出 | 提交两段后，在目录选择等待期间全不选并修改切点；原批范围保持不变，两段均完成编码并关闭文件写入流，回读文件大小 83,094 / 58,175 字节 |
| `verify-selection-timeline.cjs` | 真实解码、播放与寻道、原子裁边、不可变参考证据、取消拖动、排除与恢复、撤销/重做、悬停、独立缩放和导出通过 |
| `verify-directory-export.cjs` | 无目录能力、取消目录选择与重试、实际保存、目录复用、撤销授权后重选通过 |
| 1440 / 768 / 390 像素 | 无水平溢出；未勾选和已排除列表、恢复按钮及时间轴可用；浏览器页面脚本异常为 0 |

浏览器回归使用新建的无界面 Chrome 上下文，没有操作用户已有浏览器标签。12 秒合成媒体实际经过解码和模型分析，交互用候选范围固定为 2–5 秒和 8–10 秒，便于精确断言。导出使用真实浏览器文件系统目录（OPFS），目录选择器由测试提供该目录；本次不重复宣称原生系统目录弹窗或外接卷拔插验收。测试浏览器关闭后临时目录随上下文清理。

旧双时间轴脚本同时补齐现有 ADR 0006 流程的测试接入：导出提供真实目录句柄，并从导出页返回复核页后再操作撤销。没有修改导出调度或编码实现。
