# 03: 播放器合体全片进度条（内置全片定位、枪声候选微标与当前缩放视野框）

**What to build:** 移除时间轴面板下方原本独立占一行的「全片概览」滑块区域，参考主流在线播放器与 LosslessCut 的交互直觉，将始终代表原录像完整时长（`0 ~ duration`）的全片定位进度条直接合体嵌入 16:9 视频画面底沿与停靠播控栏之间。在该合体进度条内常驻渲染全片所有稳定枪声候选片段的位置微标（遥测青代表普通候选，琥珀橙代表当前激活选片），并在下方时间轴处于局部放大状态时，在进度条上高亮框出当前对应的局部视野时间窗。支持用户在普通视图与全屏视图下直接点击或拖拽该合体进度条完成全片任意位置定位。最后通过真实浏览器渲染截图并交由独立前端评判 Agent 完成视觉审查。
