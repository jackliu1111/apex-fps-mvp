# 01: 分析队列与导出任务页去冗余并内联实战样本入口

**What to build:** 将录像分析队列页与导出批次任务页收敛为纯粹的核心操作面板。在录像分析页移除底部的「分析设置与运行记录」调试折叠区（自动采用默认音频模型与默认阈值完成录像分析，不再向用户暴露运行耗时 JSON 与分析报告下载按钮）以及独立的「三步工作流说明」面板，同时将「试用 1 分钟实战样本」入口直接并入分析队列面板头部与空状态拖拽区，使用户打开页面即可导入原录像或一键体验实战样本。在导出批次页移除底部的长篇「输出规格与保存说明」折叠区，仅保留输出目录选择与导出批次进度列表。最后通过真实浏览器渲染截图并交由独立前端评判 Agent 完成视觉审查。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 录像分析页不再展示「分析设置与运行记录」抽屉与独立的「三步工作流说明」面板，导入原录像后默认使用既定音频模型与默认阈值自动推进录像分析。
- [x] 「试用 1 分钟实战样本」入口直接内联在分析队列面板中（空状态与队列头部均可直接触发），点击后可正常加载样本并进入分析队列。
- [x] 导出批次任务页不再展示底部的「输出规格与保存说明」折叠区，输出目录选择、批次进度展示、取消与重试等行为保持完整。
- [x] 更新并运行相关的自动化验证测试，确保无因移除调试与说明节点导致的报错或回归。
- [x] **独立前端渲染评判 Agent 验收**：在真实浏览器桌面视口（1440×900）与窄屏视口下对录像分析页（空状态、有任务态）及导出批次页进行渲染截图，启动独立前端评判 Agent 审查截图，确认视觉焦点集中于队列与任务本身、留白与对齐克制统一、无调试信息残留且评判通过。
