# 04: 单条主工作轴合体与复核台单屏零滚动收口（LosslessCut 纯净波形风）

**What to build:** 将片段复核页原本上下分离的「原片时间轴」与「预测区间轴」合并为唯一一条可缩放的「单条主工作轴」，并将两套轴头工具栏合并为轨道上方唯一一行工具栏（左侧为选片编辑动作组，右侧为视野缩放组）。主工作轴采用 LosslessCut 式的纯净视觉分层：内凹暗色轨道槽底层仅绘制高对比度渐进式音频波形（移除常驻缩略图墙，避免图像花纹干扰波形峰值与选区识别，改为鼠标悬停轨道时弹出关键帧预览气泡），中层绘制可点击的枪声候选片段区间块，顶层绘制当前激活选片的琥珀橙边界框、左右 18px 裁剪手柄及贯穿播放头。点击任意候选块或按 `[` / `]` 切换上/下一段时，主工作轴自动平滑缩放到该片段约 3 倍邻域窗口以便直接拖拽手柄精修请求导出范围；支持滚轮缩放、横向平移与一键回到全片视野。同时收口一体化单面板工作台的垂直高度预算，确保在标准桌面视口（1440×900 / 1280×800）下整页零垂直滚动，并同步更新 `DESIGN.md`。最后由独立前端评判 Agent 对全站渲染结果进行终审。

**Blocked by:** 02: 片段复核页移除三大底部折叠抽屉并收束单行工具栏与顶底栏, 03: 播放器合体全片进度条（内置全片定位、枪声候选微标与当前缩放视野框）
