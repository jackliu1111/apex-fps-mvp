# 02: 片段复核页移除三大底部折叠抽屉并收束单行工具栏与顶底栏

**What to build:** 对片段复核工作区进行去抽屉化与高频动作直连。将设起点（`I`）、设终点（`O`）、适配片段、加入导出切换（`K`）、在当前播放位置新增手动选片（`N`）、排除选中（`Del`）、撤销/重做及显示已排除等人工复核决定完全解耦为工作轴工具栏的一等直接操作，不再依赖底部折叠抽屉内的控件。彻底移除片段复核页底部的三个折叠抽屉（「精细裁剪与局部视野」、「选片列表与批量操作」、「筛选与选片规则」），并将顶部的「返回 / 原录像切换 / 录像分析进度」与底部的「已选汇总 / 格式选择 / 查看任务 / 提交选片导出」分别收束为紧凑的单行顶栏与单行底栏。最后通过真实浏览器渲染截图并交由独立前端评判 Agent 完成视觉审查。

**Blocked by:** 01: 分析队列与导出任务页去冗余并内联实战样本入口

**Status:** done

- [x] 片段复核页底部的「精细裁剪与局部视野」、「选片列表与批量操作」、「筛选与选片规则」三个折叠抽屉被完全移除。
- [x] 工具栏按钮与快捷键（`I`、`O`、`K`、`N`、`Del`、`Ctrl/Cmd+Z`、适配片段、显示已排除）作为独立一等动作直接生效，人工复核决定的保留、排除、恢复与请求导出范围调整完整可用。
- [x] 片段复核页顶部收束为单行紧凑顶栏（返回、标题、原录像分析进度、当前原录像切换），底部收束为单行导出汇总与提交栏（已选段数与总时长、导出格式选择、查看导出任务、提交选片导出）。
- [x] 迁移并运行原先依赖展开底部折叠抽屉的浏览器自动化测试，使其全部通过工具栏与时间轴直接交互并保持全绿。
- [x] **独立前端渲染评判 Agent 验收**：在真实浏览器下截取片段复核页渲染图，由独立前端评判 Agent 评判顶栏、工具栏与底部导出栏的紧凑度、按钮分组秩序、字号层级（主操作与正文保持 13–14px、时间码采用 `tabular-nums` 等宽数字）及去抽屉后的界面整洁度，确认评判通过。
