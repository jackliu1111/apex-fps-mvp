# 06 · 排除和撤销后导航使用正确片段

**What to build:** 用真实导航按钮检验排除中间段和撤销对当前录像的影响。

**设计分支**　R2 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　一份含三个稳定片段的录像，另一份录像保留已知选片。

**Status:** completed

## 验收标准

- [x] 排除中间段，从第一段点下一段到第三段；核对选中身份和显示画面。
- [x] 撤销后重新从第一段导航，中间段恢复原身份、范围和可达性。
- [x] 打开另一录像核对其选片，排除与撤销均未改变该录像的决定。

## 验证记录

- 在 `05358c9` 加 01 共用帧号素材的工作树上，运行 `node model_web_ui/browser.prototype/tests/verify-exclusion-navigation.cjs`。本机端口 18906，macOS Chrome 158.0.8127.37，两份 12 秒、12 fps VP8 录像。
- 排除 A 中间段后从 A 帧 12 点击下一段，到末段帧 96；撤销后再次从帧 12 点击下一段，回到中间段帧 48。复核了中间段原 ID、4–6 秒范围与导出决定。
- B 的两段分别取消和保留勾选，中途及重新打开 B 后均保持，显示 B 帧 12。用例运行通过。
