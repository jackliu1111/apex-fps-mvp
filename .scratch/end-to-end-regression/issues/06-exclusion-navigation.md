# 06 · 排除和撤销后导航使用正确片段

**What to build:** 用真实导航按钮检验排除中间段和撤销对当前录像的影响。

**设计分支**　R2 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　一份含三个稳定片段的录像，另一份录像保留已知选片。

**Status:** ready-for-agent

## 验收标准

- [ ] 排除中间段，从第一段点下一段到第三段；核对选中身份和显示画面。
- [ ] 撤销后重新从第一段导航，中间段恢复原身份、范围和可达性。
- [ ] 打开另一录像核对其选片，排除与撤销均未改变该录像的决定。
