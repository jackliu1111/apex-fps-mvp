# 04 · 导航显示正确帧并处理间隙及分析尾部

**What to build:** 在现有导航断言上补实际显示帧、间隙的两个方向以及分析未结束的末段。

**设计分支**　N1、N2、N3 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　固定帧率录像，两个稳定片段为 4–6 秒和 8–10 秒，可保持分析中状态。

**Status:** ready-for-agent

## 验收标准

- [ ] 第二段中途点击上一段，选中第一段；显示帧与 4 秒相差最多一个帧周期。
- [ ] 两次独立从 7 秒出发，即使此前有选中片段，点上一段到 4 秒，点下一段到 8 秒；同时核对片段身份与画面。
- [ ] 在分析中的末段点击下一段，出现后续仍在分析的提示，选中项及暂停帧保留。复用现有首段和已完成末段的禁用断言。
