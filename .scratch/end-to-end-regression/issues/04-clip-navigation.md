# 04 · 导航显示正确帧并处理间隙及分析尾部

**What to build:** 在现有导航断言上补实际显示帧、间隙的两个方向以及分析未结束的末段。

**设计分支**　N1、N2、N3 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　固定帧率录像，两个稳定片段为 4–6 秒和 8–10 秒，可保持分析中状态。

**Status:** done

## 验收标准

- [x] 第二段中途点击上一段，选中第一段；显示帧与 4 秒相差最多一个帧周期。
- [x] 两次独立从 7 秒出发，即使此前有选中片段，点上一段到 4 秒，点下一段到 8 秒；同时核对片段身份与画面。
- [x] 在分析中的末段点击下一段，出现后续仍在分析的提示，选中项及暂停帧保留。复用现有首段和已完成末段的禁用断言。

## 验证记录

macOS Chrome，工作树基线 52d0622。运行 `node model_web_ui/browser.prototype/tests/verify-navigation-frames.cjs` 通过。
12 秒 B 素材以 12 fps 烧录源与帧号。第二段播放中和两次从 7 秒间隙跳转，实际解码帧分别在第 48、96 帧一帧容差内，片段身份匹配。已结束的末段下一段禁用，分析中末段点击后显示提示，保留同一暂停帧和选中项。
