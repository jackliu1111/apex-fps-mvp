# 03 · 批量导入逐文件对账

**What to build:** 将文件输入框、行状态、队列和脱敏诊断的结果逐份对应。

**设计分支**　I1、I2、I4 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　三份短视频，用文件名及不同时长区分；可暂缓 C 的准备和控制 A 的完成。

**Status:** ready-for-agent

## 验收标准

- [ ] 初始读取身份时三行各对应一个所选文件；复用已有重复文件和坏文件检查，按文件名确认归属。
- [ ] 同时观察 A 正在分析、B 排队、C 读取轨道；B 不显示识别百分比，C 准备期间 A 继续推进。
- [ ] 放行后队列耗尽，三份文件均就绪。用已知时长等脱敏信息逐项核对诊断与列表终态。
