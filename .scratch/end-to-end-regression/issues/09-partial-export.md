# 09 · 第二段写入失败后的取消与恢复

**What to build:** 在同一批次的第一段已关闭、第二段写入中失权时，分别验证取消和恢复。

**设计分支**　E3、E4 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　至少三段，能向写入中的第二段注入权限错误，支持目录重选、残件清理失败和读回。

**Status:** ready-for-agent

## 验收标准

- [ ] 从产品页提交后修改当前选片。第一段成功、第二段开始写入后注入错误，面板提示重选目录，已保存数为 1，第一段可读。
- [ ] 取消分支保留第一段，停止余项；恢复分支只写余项，第一段不重复写、内容不变，最终目录与原批次快照逐文件一致。
- [ ] 注入清理失败时，面板给出实际残件位置。记录错误发生时点，区分段间撤权和写入中失权。
