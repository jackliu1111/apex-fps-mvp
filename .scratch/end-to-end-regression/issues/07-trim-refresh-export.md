# 07 · 后台更新后导出采用人工裁边范围

**What to build:** 从用户拖动裁边到实际提交导出，检查中途发布的自动候选不会覆盖人工决定。

**设计分支**　R3 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　同源录像可分两次交付候选，在第二次交付前完成手动裁边。

**Status:** ready-for-agent

## 验收标准

- [ ] 在界面拖动裁边并记录范围、焦点与导出勾选状态；放行下一批自动候选后逐项核对。
- [ ] 通过导出按钮提交，检查批次源和片段范围精确等于裁后的选片。
