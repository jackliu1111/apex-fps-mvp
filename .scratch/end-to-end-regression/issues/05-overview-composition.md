# 05 · 全片播放轴合成画面与候选更新

**What to build:** 验证用户实际看到的红色枪声、区间边界和全屏退出后的定位。

**设计分支**　T1、T2、T3 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　可截图的浏览器；8.04 秒有枪声，临时候选为 8.00–8.06 秒；准备已知人工决定。

**Status:** ready-for-agent

## 验收标准

- [ ] 在普通、全屏和退出全屏后检查最终合成像素，区间内红色可见，左右边界各与对应时刻相差小于 1 CSS 像素。
- [ ] 暂停时放行同一候选的稳定更新，只有一个标记，虚线转为稳定样式，暂停帧和人工决定保留。
- [ ] 退出全屏后拖动全片轴，按恢复后的轨道宽度核对终点、读数与解码帧。
