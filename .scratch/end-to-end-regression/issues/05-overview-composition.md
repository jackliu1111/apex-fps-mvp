# 05 · 全片播放轴合成画面与候选更新

**What to build:** 验证用户实际看到的红色枪声、区间边界和全屏退出后的定位。

**设计分支**　T1、T2、T3 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　可截图的浏览器；8.04 秒有枪声，临时候选为 8.00–8.06 秒；准备已知人工决定。

**Status:** done

## 验收标准

- [x] 在普通、全屏和退出全屏后检查最终合成像素，区间内红色可见，左右边界各与对应时刻相差小于 1 CSS 像素。
- [x] 暂停时放行同一候选的稳定更新，只有一个标记，虚线转为稳定样式，暂停帧和人工决定保留。
- [x] 退出全屏后拖动全片轴，按恢复后的轨道宽度核对终点、读数与解码帧。

## 验证记录

macOS Chrome，基线 52d0622，`node model_web_ui/browser.prototype/tests/verify-overview-composition.cjs` 通过。测试在 Chrome 完成布局后截取最终画面，普通、全屏、退出全屏三种状态下的轨道宽度分别为 1214.125、1098、1214.125 CSS 像素；8.00–8.06 秒区间内分别有 24、18、24 个可见红色像素，两端位置误差各小于 1 CSS 像素。更新候选后原有人工取消勾选和暂停帧保留，退出全屏拖动至 9 秒后时间、读数与 B 的烧录帧一致。
