# 01 · 后台分析完成时保留前台暂停与播放

**What to build:** 分别在 B 暂停和播放时放行 A 的分析结果，验证随后操作的录像归属。

**设计分支**　B1、B2 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　A、B 画面带有独立源标识和帧号，A 首段从 1 秒开始，B 首段从 4 秒开始。可控制 A 的分析结果交付。

**Status:** ready-for-agent

## 验收标准

- [ ] B 第二段暂停在 8.5 秒时放行 A。A 行显示就绪且有 3 段，B 仍选中第二段，暂停帧保留，意外重载 0 次。
- [ ] 点一次「上一个」后选中 B 第一段，画面时间与 4 秒相差最多一个素材帧周期。
- [ ] 另一起始状态中，B 的画面已连续播放才放行 A。事件前后均看到 B 的递增帧，无回跳或暂停，点击暂停后停住 B。两条用例可独立运行。
