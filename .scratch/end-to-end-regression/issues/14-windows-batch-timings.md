# 14 · Windows 批量导入分段耗时基线

**What to build:** 在报告问题的平台上对照单份和批量导入，定位耗时所在阶段。

**设计分支**　I1、I2、I4 · [端到端回归测试设计](../../../docs/design/end-to-end-regression.md)

**Blocked by:** None (can start immediately)

**执行条件**　实机验收。Windows Edge、授权使用的录像、原存储位置。

**Status:** ready-for-agent

## 验收标准

- [ ] 同机同素材分别进行单份和批量导入，记录版本、存储位置类型和导入顺序。
- [ ] 逐文件记录从选入到出现行、读取轨道、等待队列、分析启动及首个可复核片段的时间。无候选或观测缺失的阶段按实际标注。
- [ ] 结合队列与界面解释任务未启动、排队和读取慢的区别；即使未复现，也提交原始观测和环境信息，本轮以建立基线验收。
