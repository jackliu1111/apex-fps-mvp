Output Specs & Saving Notes
Each clip is exported individually as , with audio from the source default track. Resolution and frame rate are preserved; re-encoding is not lossless. Exports execute once analysis frees up resources, during which review can continue.
Clips stream directly into the chosen folder and are marked saved once write streams close successfully. For large batches, pick a mounted external drive folder with sufficient space. Desktop Chrome or Edge is recommended.
