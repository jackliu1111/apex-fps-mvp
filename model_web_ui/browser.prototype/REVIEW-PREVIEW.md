# 片段复核场景环境

启动：`python3 model_web_ui/browser.prototype/serve.py --port 8794 --background`
依赖已有 runtime assets，默认 `/private/tmp/apex-browser-prototype-20261026/assets`；其他位置用 `--assets` 指定。

打开 http://127.0.0.1:8794/?reviewPreview=default 。下拉框切换场景，重置按钮恢复初始条件。

| 参数 | 检查目标 |
| --- | --- |
| default | 两条候选，播放、裁边、排除、撤销与重做 |
| analyzing | 已处理 6 / 12 秒时仍可复核；进度为固定模拟值 |
| empty | 无候选时手动添加范围 |
| many | 40 条候选的列表、时间轴与选择 |

复用正式 app.js、review-workspace、source-player、selection-timeline。仅输入夹具不同，不复制 UI。修改正式组件后刷新本预览即可检查。

预览不读写正式 IndexedDB 或页面位置 localStorage。每次刷新重新生成小型 12 秒合成录像，不下载模型，不运行推理。录像可真实解码播放，但不能证明 Apex 对局识别质量或长录像性能。页面其他操作仍使用正式实现；导出会实际生成合成片段。

新增场景：在 review-preview.mjs 的 scenarios 中注册，并提供候选、分析状态或存储行为。保持模拟边界可见，不把固定进度描述成真实分析。

验收步骤：选择候选 → 调整起终点 → 排除 → 撤销 → 检查恢复；刷新后重新生成预设场景。正式入口不带 reviewPreview 参数，刷新后为空工作区。

本轮未接入 Storybook 或 Figma；这是已有应用的组件场景预览入口。导出失败场景和真实对局媒体验收尚未纳入本场景集。

## 真实波形设计样本

打开 `?reviewPreview=sample`。使用 `selection-design/media/waveform.json` 中已保存的 60 秒交战声音峰值，六段区间来自设计预设，共 20.9 秒。Figma 使用相同峰值和区间。

波形以底部为基线向上绘制；区间透明叠加，与波形共用位置、宽度和时间范围。排除与撤销不改变声音证据。预载 `media/frame-{0,5,…,55}.jpg` 共 12 张真实对局参考帧：大图显示当前时间之前最近一张，缩略图带按当前可见时间窗取样。切换候选会同步定位，大图保持原始宽高比。静态帧并非逐帧解码或连续播放；需要真实播放时在正式入口导入录像。

## 快速视觉迭代

优先打开 `?reviewPreview=sample` 修改正式组件与样式，刷新即可恢复六段预设区间。当前编辑区间使用亮绿色填充、加粗起止边界与顶部标记；其他区间使用浅灰绿轮廓与顶部条；排除区间仍为虚线。波形仅降低显示不透明度，不改峰值数据。候选列表的当前行显示“当前编辑”。

需要播放验证时切换 `default` 合成录像场景，或在正式入口导入真实样本录像。新状态优先添加到现有场景选择器，避免另外维护一套静态界面。视觉确认后，改动已在正式组件中，无需从设计稿再次搬运。
